# 设备与连接

## 本次设备

铭牌型号：**MCEA-3G-02-050-C-W-F**，DH-Robotics（大寰机器人），微型滑台电缸。

`02`表示2 mm导程，`050`表示50 mm行程，`C`表示驱动内置，`W`表示带抱闸。`F`为出线方向代码，具体线序以本机线标与对应版本手册为准。序列号只保存在本地，不随本公开项目发布。

| 厂家目录规格 | 对应值 |
|---|---|
| 行程 / 丝杆导程 | 50 mm / 2 mm |
| 额定推力 | 100 N |
| 最大速度 / 最大加速度 | 100 mm/s / 3000 mm/s² |
| 水平 / 垂直最大负载 | 6 kg / 1.5 kg |
| 重复定位精度 | ±0.01 mm |
| 工作电压 | DC 24 V ±10% |
| 额定 / 峰值电流 | 1.5 A / 3 A |
| 防护等级 | IP40 |

这些是[厂家产品页](https://www.dh-robotics.com/product/mcea)中对应配置的规格，不是测量值；负载受安装方式和偏载力矩限制。

## 已验证通信

| 项目 | 结果 |
|---|---|
| 转接器 | FTDI USB Serial Converter，VID0403/PID6001 |
| 电脑串口 | COM3，仅为本次枚举结果 |
| 总线 / 协议 | RS485 / Modbus RTU |
| 站号 / 波特率 | 1 / 115200 |
| 串口格式 | 8N1：8数据位，无校验，1停止位 |

USB转接器被识别不等于电缸已响应，也不代表已提供24 V供电。本项目使用CRC正确的设备应答确认通信；寄存器读回不能单独证明铭牌型号和序列号。

首次接线需核对24V、GND、485A/TR+、485B/TR-线标。线缆颜色可能随版本变化，不按照片颜色猜测。竖直安装、带抱闸版本，不在未支撑负载时失能或强制松抱闸。

## 实际配置差异

本次读取行程限制为50.85 mm、原点偏置为1.00 mm，不能据此扩大铭牌50 mm的允许运动范围。测试额外保留余量：下界为`1 mm + |原点偏置|`，上界为`min(50 mm, 行程限制) - 1 mm - |原点偏置|`；本机对应2～48 mm。它是本程序的保守测试范围，不是厂家通用限位公式。

只读参数快照及原始帧属于本地运行数据，不自动发布。固件版本、电子序列号和非公开工厂参数没有取得，不能称为完整EEPROM备份。
