# 操作与恢复

## 参数读取

按README安装依赖，先执行`mcea_read.py`。`--probe`只读站号和回零状态；普通模式读取55项已核实地址并输出带时间戳JSON。0x0204电流保存原始字；0x160D文档标注mA，但有符号解释仍需固件核对，不将它作为推力测量。

## 回零

运行`mcea_home.py --check`先读状态，去掉`--check`后输入HOME才启动。程序要求无报警、已使能、未运动、I/O关闭、回零方向仍为本次核实的1。方向1为后退端寻找；并非把当前位置直接设为零。

触发顺序按厂家手册：使能保持、回零位清零，再将回零位设1产生上升沿。程序不改变回零方向、原点偏置或Flash。回零中轮询报警和状态，成功必须同时满足回零状态1、状态字回零完成位为1、运动位为0并稳定多次。25秒内未确认则报错并尝试暂停。

寻找端部时外部障碍可能被误认为端部，必须检查实际路径与最终位置。回零速度未核实，不保证1 mm/s。控制器已反馈回零成功时不会再次触发。暂停后的状态应先通过厂家软件检查。

## 方向测试

1. 设备需已回零、使能、静止、无报警，关闭其他控制软件。
2. 若从0 mm开始，使用`--center`：先以1 mm/s移至25 mm，再读取稳定位置作为新起点S。
3. 输入START确认完整路线；准备完成和后续各段输入GO。测试为S+10 → S → S-10 → S。
4. 正负方向仅指位置数值增减，到达正负目标后现场填写实际方向。
5. 每段用位置、运动位和到位位共同确认，报警、超时、偏离轨迹或通信错误时不重发运动指令。

回零完成后Bit1可能仍保留在控制字中。已验证回零完成且静止时，程序允许这一状态；下一次完整位置指令先把回零位和启动位清零，然后仅置定位启动位。不会再次触发回零。

## 中断及重新连接

Ctrl+C尝试写入0x0028（保持使能并置暂停位）。收到应答不能保证物理停止；暂停未确认时使用现场停止装置，不靠拔USB或关闭程序停机。

串口消失后，先现场确认停止及负载支撑，重新连接电缸与USB转接器，再枚举端口。不要因位置日志停在某个值就假定当前机械位置仍相同。

```powershell
& ".\.venv\Scripts\python.exe" -m serial.tools.list_ports -v
& ".\.venv\Scripts\python.exe" .\mcea_read.py --port COM3 --probe
```

端口变化时替换COM3；重新读取位置、报警和回零状态后再决定后续操作。电源重启后不能沿用旧的回零状态；无需自动接着未完成的动作继续。
